📲 如何將單字特訓安裝為 App
🍎 iPhone / iPad (iOS Safari)
  1. 使用 Safari 瀏覽器 開啟此特訓網頁。
  2. 點擊螢幕下方底欄的 「分享」按鈕（箭頭方塊圖示）。
  3. 在選單中點選 「加入主畫面」。
  4. 點擊右上角 「新增」 即可生成 App 圖示。
🤖 Android 手機 (Chrome 瀏覽器)
  1. 使用 Chrome 瀏覽器 開啟此特訓網頁。
  2. 點擊右上角 三個點選單圖示 (⋮)。
  3. 點選 「安裝應用程式」 或 「新增至主畫面」 即可。
